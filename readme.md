# Comment Edit Pro

**This project is being archived.** The original maintainer is stepping back. Forks are welcome. GitHub's archive flag is a repository setting; clear it when a new owner is ready to maintain the project.

Takeover notes are in [CONTRIBUTING.md](CONTRIBUTING.md). Coding agents should start with [AGENTS.md](AGENTS.md).

Comment Edit Pro (version 4.3.0) extends comment editing on WordPress and expects the free Simple Comment Editing plugin (`simple-comment-editing`). Settings are under **Settings → Comment Edit Pro**. Hooks that already have write-ups are listed in [actions.md](actions.md).
